6. Build e empacotamento

npm run dist:win        # Instalador NSIS (distribuição técnica local)
npm run dist:win:store  # Pacote MSIX assinado (fluxo Microsoft Store)
  • Instalador NSIS por usuário, sem exigir privilégios de administrador.
  • Pacote MSIX assinado digitalmente via winapp sign, com validação por Get-AuthenticodeSignature.

7. Segurança operacional para homologação

  • O aplicativo opera com persistência local-first e não envia arquivos operacionais ao fabricante.
  • O shell desktop publicado não depende de bibliotecas remotas para sua operação principal em runtime.
  • A exceção wasm-unsafe-eval existe apenas para a instanciação do módulo Rust/WebAssembly local.
  • O escopo de risco assumido exclui malware já instalado com o mesmo privilégio do usuário.
